# 定价模型

所有计算在 `src/domain/pricing/`，不依赖框架，可单独测试。

## 1. 成本

| 项目 | 公式 | 币种 |
|------|------|------|
| 货值 | 采购价 + 国内运费 + 包装费 | 成本币种（CNY） |
| 体积重 | 长 × 宽 × 高 (cm) ÷ 体积重除数；尺寸不全或除数为 0 时为 0 | kg |
| 计费重 | max(实重, 体积重) | kg |
| 头程 | max(计费重 × 单价, 最低收费) + 贴单操作费 | 成本币种 |
| 到岸成本 | (货值 + 头程) × 汇率 × (1 + 汇率缓冲) | 销售币种 |
| 尾程 | (首重费 + ⌈(计费重 − 首重) ÷ 续重档⌉ × 续重费) × (1 + 运费税) | 销售币种 |

## 2. 平台费

每个店铺有一组费用行，每行：

- `kind`：`percent` 按售价比例，`fixed` 每单固定金额
- `cap`：单笔封顶（仅 percent），如 Bonus Cashback 封顶 RM50
- `maxPrice`：只在售价 ≤ 该值时收取，如马来西亚 LVG 仅对 ≤ RM500 的跨境低值商品征收 10%
- `refundOnReturn`：退货时平台是否退还该费用（例如每单固定的平台支持费通常不退）
- `enabled`：是否启用

商品可以设置 `commissionRate` 覆盖 id 为 `commission` 的费用行（不同类目佣金不同）。

## 3. 单件期望利润

```
送达订单利润 = P − 到岸成本 − 尾程 − Σ平台费(P) − 达人佣金率·P − 广告费率·P
退货订单损失 = 尾程 + 退货运费 + 到岸成本·(1 − 可二次销售比例) + Σ不退还的平台费(P) + 广告费率·P
期望利润     = (1 − r)·送达订单利润 − r·退货订单损失
期望净利率   = 期望利润 ÷ P
```

假设：

- 退货时售价全额退还买家；
- 达人佣金只对成功订单结算；
- 广告费按售价比例分摊，退货订单的广告费已经花出去；
- 退回的货按"可二次销售比例"收回到岸成本，其余计为损失。

## 4. 反推售价

目标：找到最低的 P，使 `期望利润(P) ≥ 目标净利率 × P`。

封顶和价格阈值让期望利润成为 P 的**分段线性函数**，拐点为每条费用的 `cap ÷ 费率` 和 `maxPrice`。求解器逐段拟合直线并求根，取最小的可行解：

- 段内斜率 > 0：根落在段内即为解；根在段起点之前说明整段都满足，取段起点；
- 跨过 `maxPrice` 后费用消失、利润突然变高的情况，会返回阈值之上的最低价；
- 所有段都不满足（费用比例之和 ≥ 1 − 目标净利率）时返回 `null`，界面显示"目标不可达"。

求得的价格按店铺的取整规则**向上**取整：取到 `step` 的整数倍再加 `ending`（如 step=1、ending=0.9 → 以 .90 结尾）。向上取整不会让利润率低于目标。

保本价即目标净利率为 0 时的解，按分取整。

## 5. 其他指标

- **价格阶梯**：引流 / 利润 / 锚定三档目标净利率分别对应的价格；
- **最多可让利**：`1 − 保本价 ÷ 最终价`，报活动时的折扣上限；
- **汇率压力测试**：成本币种升值 5% 时，最终价下的期望净利率；
- **预警**：亏损、现价亏损、低于目标、目标不可达、抛货、缺重量。
