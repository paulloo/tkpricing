# 贡献费率预设

预设在 `src/domain/presets.ts`。创建店铺时会把预设的配置**复制**到店铺里，之后修改预设不会影响已有店铺。

## 新增或更新预设

1. 复制一个现有预设，`id` 使用 `<站点>-<店铺类型>-<YYYY-MM>`，如 `th-cross-border-2026-11`；
2. 填写每条费用：
   - 费率统一用小数（3.78% → `0.0378`），并说明**是否含税**；
   - 有封顶就填 `cap`，只对一定价格以下收取就填 `maxPrice`；
   - 在 `note` 写清楚生效日期和适用范围；
3. 填写 `verifiedAt`（核对日期）和 `sources`（**必须**，最好是卖家中心 / 卖家大学的官方页面）；
4. 物流费如果只是示例值，请在 `description` 里写明；
5. 运行 `pnpm test`：会检查每个预设都能通过配置校验、核对过的预设都有来源。

旧预设不要删除，保留历史版本方便对比；把新预设放在同站点旧预设之前，它就会成为新建店铺时的默认选项。

## 不确定的数字

不要填猜测值。查不到可靠来源时，宁可保留空白模板（`verifiedAt: null`），在 PR 里说明缺什么信息。
